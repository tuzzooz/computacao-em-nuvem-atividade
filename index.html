1 O que é Computação em Nuvem?

Segundo a definição canônica do NIST (Special Publication 800-145), a computação em nuvem é um modelo tecnológico que permite acesso onipresente, conveniente e sob demanda por meio de rede a um conjunto compartilhado de recursos computacionais configuráveis (tais como redes, servidores, armazenamento, aplicações e serviços), capazes de serem rapidamente provisionados e liberados com mínimo esforço de gerenciamento ou interação com o provedor de serviços.

2 As Cinco Características Essenciais (NIST SP 800-145)

  • Autoatendimento sob Demanda (On-demand Self-service): O usuário provisiona recursos (CPU, armazenamento, rede) unilateralmente e automaticamente, sem precisar de aprovação manual do suporte.
  • Amplo Acesso à Rede (Broad Network Access): Recursos disponíveis via rede acessíveis por mecanismos padronizados em plataformas heterogêneas (smartphones, tablets, notebooks e estações de trabalho).
  • Pool de Recursos Compartilhados (Resource Pooling): Os recursos computacionais do provedor são agrupados para atender múltiplos clientes no modelo multi-tenant, com alocação dinâmica e isolamento lógico.
  • Elasticidade Rápida (Rapid Elasticity): Capacidades computacionais podem ser elástica e automaticamente escaladas para cima ou para baixo, acompanhando flutuações de demanda em tempo real.
  • Serviço Mensurável (Measured Service): O uso de recursos é monitorado, controlado e cobrado de maneira transparente através de métricas precisas (modelo pay-as-you-go).

3 Modelos de Serviço em Nuvem

IaaS (Infraestrutura)

Fornece máquinas virtuais, discos e redes brutas. O cliente gerencia o Sistema Operacional, runtimes e aplicações. Ex: AWS EC2, Azure VM, DigitalOcean.

PaaS (Plataforma)

Fornece o ambiente de execução pré-configurado. O cliente gerencia apenas código e dados. O provedor cuida de SO, escalabilidade e patches. Ex: Vercel, Render, AWS Elastic Beanstalk.

SaaS (Software)

Software completo pronto para consumo final via web ou aplicativo. O cliente apenas consome e configura usuários. Ex: Google Workspace, Microsoft 365, Salesforce.

4 Análise Técnica desta Publicação

Esta página web representa a aplicação prática do modelo Platform as a Service (PaaS) / Static Web Hosting. Para sua publicação, coube ao desenvolvedor exclusivamente a elaboração do código (HTML, CSS e conteúdo semântico) e o envio do artefato para a plataforma. Toda a infraestrutura subjacente — incluindo provisionamento de servidores web de alta performance, configuração de zonas DNS, emissão e renovação automática de certificado criptográfico SSL/TLS (HTTPS), compressão de arquivos, roteamento e distribuição geográfica em Edge Locations via CDN (Content Delivery Network) — ficou integralmente sob a responsabilidade do provedor de nuvem.
